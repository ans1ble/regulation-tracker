# memory/ 使用约定（与周报去重）

本目录是「法规事实库」，与 `reports/<year>/weekly/` 周报是**两层不同职责**，目标是避免同一事实在两处重复陈述。

## 三层结构

| 层 | 位置 | 职责 | 是否对外事实 |
|----|------|------|--------------|
| 周报（正史 / 时间线） | `reports/<year>/weekly/Wxx.md` | 记录「某周发生了什么」，含完整叙事、影响分析、来源链接 | 是（溯源依据，永不删减） |
| 知识库（当前状态） | `memory/regulation-knowledge-base.md` | 每个法规一行，记录「现在处于什么状态 / 何时生效 / 要求」，随法规演进**就地更新** | 是（当前快照） |
| 日记（过程笔记） | `memory/YYYY-MM-DD.md`、`memory/work/daily/` | agent 自身工作记录（发现、待核实、复核） | 否（不与周报重复叙事） |

## 去重规则

1. 同一法规在知识库只保留一行；新动态**就地更新**该行，不追加新行。
2. 知识库行只写「当前状态」，背景 / 影响分析 / 长来源说明留在周报；知识库通过「来源周报」列链回对应周报，不复制内容。
3. 生成周报时把完整内容写进周报；知识库只更新 / 新增对应的一行（含「来源周报 = Wxx」）。
4. 待核实项只在知识库标 ⚠️，并同步到根 `MEMORY.md` 的「当前待核实项」；不在周报里静默放过。
5. 日记文件记录过程，不重复周报与知识库已有的事实陈述。

详见 `SKILL.md` 的「知识库更新」一节。
