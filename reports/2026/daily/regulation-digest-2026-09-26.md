## 🔴 紧急动态（新规生效 < 3个月）

### 1. 美国 CMMC 2.0 第三/四阶段评估暂停转为具有法律约束力的法规
- **来源**: [Washington Technology – CMMC's Phase 2 suspension locked in with binding regulation (2026-09-09)](https://www.washingtontechnology.com/contracts/2026/09/cmmcs-phase-2-suspension-locked-in-binding-regulation/415883/)
- **生效日期**: 2026-09-03 发布 class deviation 备忘录（John Tenaglia，DOD 定价/采购政策首席总监），近期已正式锁定为具有约束力的法规
- **影响产品**: 向美国国防部供货的国防工业基础（DIB）企业，涉及工控/OT系统、网络安全产品的供应商
- **核心变化**: DOD 将原本的政策性暂停（suspension）转为具有法律约束力的 class deviation，要求 contracting officers 按照 Revolutionary FAR Overhaul 而非 2025年11月生效的最终 CMMC 规则执行合同条款；所有合同中 CMMC 第三方评估要求须删除。自审（self-attestation）仍为强制要求。CMMC 改革特别工作组（60天审查）于 2026-07-13 启动，截止 2026-09-11；已收到 1,100+ 份公众意见。
- **定级依据**: CMMC 是出口美国国防相关产品的强制性认证体系；第三/四阶段第三方评估的暂停（原定 2026年11月启动）直接影响国防承包商合规路径；从"suspension"转为"binding regulation"使逆转程序更复杂
- **行动建议**: [ ] 国防承包商须确认合同条款已按 class deviation 修订；[ ] 关注 CMMC Reform Task Force 报告发布及后续 Phase 3/4 决策；[ ] 自审合规要求不变，需确保 NIST 800-171 控制措施有效落实

### 2. 三菱电机 MELSEC iQ-R 系列安全 PLC 获 EU 机械法规类型认证（TÜV Rheinland）
- **来源**: [Mitsubishi Electric 官方公告 / LawmonGlobal（2026-09-25 报道）](https://www.lawmonglobal.com)
- **预计生效**: 证书已颁发，立即有效
- **影响产品**: 出口欧盟的工业自动化设备、安全可编程控制器（PLC）、集成 MELSEC iQ-R 系列安全控制器的高压电气产品
- **核心变化**: 三菱电机 MELSEC iQ-R 系列安全 PLC 获得 TÜV Rheinland 颁发的 EU 机械法规（EU) 2023/1230 型式检验证书（EU type examination certificate）。该法规于 2027年1月1日起强制实施，取代旧版机械指令 2006/42/EC。
- **定级依据**: 机械法规是出口欧盟自动化设备的关键准入要求；此认证表明三菱已为新规过渡做好准备，同行厂商需对标评估自身产品合规状态
- **行动建议**: [ ] 评估产品中涉及的 PLC/安全控制器是否已完成机械法规符合性评估；[ ] 关注同类厂商认证动态
